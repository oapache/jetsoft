# Jetsoft Clone

Clone visual responsivo da página institucional fornecida em `https://jetsoft.com.br/`.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra o endereço indicado pelo Vite. O ponto de entrada é `/`.

## Fonte visual

- `DESIGN.md`: direção, tokens e regras de composição.
- `src/design/tokens.css`: tokens executáveis.
- `PRODUCT.md`: contexto do produto e restrições preservadas.
